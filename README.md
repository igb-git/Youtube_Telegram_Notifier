**TELEGRAM BOT FOR AUTOMATICALLY ADDING MESSAGES TO A CHANNEL**

1. Gets videos from a list of RSS feeds from YouTube Channels
2. Loads last date the program was run from last_date.txt
3. Selects the videos in the feed after that date
4. Creates message in a Telegram Channel using a bot in that channel
